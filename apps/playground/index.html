Install

        
Three steps to a living mascot.

        
Works anywhere you can write a tag: plain HTML, React, Vue, Svelte. No build plugin, no assets to host.

      


      

        
    
          
  1. 
            
    Add the packages
    
            
    npm install @wobnimo/engine @wobnimo/characters
    
            
    Publishing to npm soon. Until then, build from the repository.
    
          
    2. 
          
  2. 
            
    Register the element once
    
            
    import { defineWobnimoElement } from '@wobnimo/characters';
defineWobnimoElement();
    
          
    3. 
          
  3. 
            
    Drop it in and drive it

Size & speed

        
Smaller than a thumbnail. Smooth on a phone.

        
No sprites, no textures, no video. Shapes, light and motion are all maths, so a character costs less to download than its own avatar image.

      


      

        
24 KBThe whole engine, minified and gzipped

        
~2 KBAn average character, gzipped

        
1Draw call per mascot per frame

        
0Dependencies and image files

      


      

        
What ships, to scale

        

      


      
    
        
  • Sleeps when unseen. Mascots scrolled out of view or in a background tab stop drawing.
    • 
        
  • Adapts to the device. If frames run long, it renders fewer pixels until the GPU catches up.
    • 
        
  • Shares its work. Ten copies of one character compile one shader and run on one animation loop.
    • 
        
  • Respects reduced motion. It holds each state's pose instead of animating.
