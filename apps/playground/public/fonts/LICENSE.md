# Fonts

Anton (Vernon Adams), Caveat (Impallari Type) and JetBrains Mono (JetBrains), from Google Fonts,
each under the SIL Open Font License 1.1: https://openfontlicense.org

They are self-hosted so the page needs no third-party request before it can draw. Each file is
cut down to Latin, Caveat and JetBrains Mono to the weights the page uses (500–600 and 400–700).
